# Tu Sexualidad En Armonia

All technical instructions are in English, but every user-facing element of the website must be written in natural, fluent, international Spanish.

Do not translate the brand name TuSexualTip. Do not display English text anywhere on the website, including buttons, forms, error messages, notifications, navigation, and footer.

The target audience is Spanish-speaking adults aged 18 and older worldwide.
